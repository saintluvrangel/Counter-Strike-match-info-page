      Импорт демо в матч

      Root / Admin

      Выберите матч и карту серии для одного .dem. Чтобы добавить все карты BO3/BO5, загрузите ZIP со всеми демками и включите соответствующий флажок. Можно вставить прямую HTTPS-ссылку на файл демо.

      Файл не выбран
      Парсер заполнит карту, события раунда, гранаты и доступную статистику.
      Демо сохраняются локально на сервере: до 1 ГБ для .dem и до 5 ГБ для ZIP. Карты архива сопоставляются с матчем по названию внутри демо.
